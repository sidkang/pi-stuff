# @sidkang/pi-try-serve

Pi skill that shares one HTML file or a prepared static directory through a temporary public Cloudflare Quick Tunnel.

Requires Node.js 18+, `screen`, and `cloudflared` on `PATH`. No Cloudflare account is needed.

```sh
pi install npm:@sidkang/pi-try-serve
```

See [SKILL.md](skills/try-serve/SKILL.md) for usage.

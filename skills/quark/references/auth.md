# 授权与登录

## 检查或建立登录

```bash
./scripts/quark-drive.cjs login
```

`login` 先检查本地账号并向服务端验证。已有授权有效时返回成功，不打开授权页、不要求退出重登：

```json
{"code":0,"msg":"已登录夸克网盘（账号昵称），授权有效","data":{"status":"already_authorized","nickname":"账号昵称"},"action":"login","type":"result"}
```

进程退出码为 0。告诉用户账号仍可访问即可；若正在执行文件任务，则继续原任务。验证账号有效不代表已经验证每个文件的访问权限，无需另做随机搜索。

没有可用授权时，CLI 尝试打开浏览器，并输出授权链接、等待用户确认。运行前说明可能需要交互；不能打开浏览器时把链接交给用户。CLI 的浏览器授权轮询约 60 秒；Pi `bash.timeout` 的单位是秒，可用 `120`，不是 `120000`。

## 授权码与恢复任务

用户完成授权后，也可以用取得的授权码绑定：

```bash
./scripts/quark-drive.cjs login --token '<授权码>'
```

`--token` 是授权码，不是配置文件中的 access token。显式传入授权码时会处理该授权码，不走已有登录的快捷返回。

业务命令提示未登录或授权失效时，先告知用户，再进入授权流程；成功后继续原任务。登录超时或失败时先说明具体原因，等待用户完成授权或提供授权码，不循环打开授权页。权限不足、网盘空间不足或分享失效不能靠反复登录解决。

授权范围可能覆盖全部网盘文件。首次授权时提醒用户可在夸克网盘 App「我的 → 登录授权管理 → 其他 AI 助手授权」检查或调整范围。不读取配置来展示凭据，不在回复中回显授权码。

## 退出或切换账号

```bash
./scripts/quark-drive.cjs logout
```

先确认用户确实要撤销本机授权。成功撤销后，CLI 清除 `~/.config/quark/config.json` 中的本地登录状态，不删除整个配置目录或 skill 文件。切换账号时先退出，再登录；不要为了修复“已登录”状态而退出。未登录时退出是成功的空操作，`data.revoked` 为 `false`。

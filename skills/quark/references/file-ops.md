# 目录、移动与隔离删除

## 选择目标

FID 是文件或目录的唯一标识；`"0"` 表示自己网盘的**根目录**。用户提供 FID 时直接使用；仅给名称时按[搜索](file-search.md)找到对应目录，同名结果先澄清，不选第一个碰运气。

上传、转存和创建目录的目标参数可省略，但只在用户没有指定目标时省略。默认位置由服务端决定，不自行补 `"0"`。找不到指定目录时询问是否创建或改用其他目标，不静默降级。用户已经要求创建的目录可以直接创建。

不要把用户业务源目录误当成根目录。隔离删除的 `/待删除` 一律建在根下（`--parent-fid '0'`），与源目录无关。

## 创建目录

```bash
./scripts/quark-drive.cjs create-folder --dir-path '项目资料'
./scripts/quark-drive.cjs create-folder --dir-path '项目资料' --parent-fid '<父目录FID>'
# 用户明确要求建在根目录
./scripts/quark-drive.cjs create-folder --dir-path '项目资料' --parent-fid '0'
```

`--dir-path` 必填，可传名称或路径。成功的 `result.data.fid` 是新建或复用目录的 FID；后续上传或移动使用这个值，不必再次搜索。`full_path` 是尽力解析出的路径信息，缺失时只报告目录名与 FID。

## 移动文件或文件夹

```bash
./scripts/quark-drive.cjs move '<FID1>' '<FID2>' --target-fid '<目标目录FID>'
```

至少一个源 FID，`--target-fid` 必填。执行前确定源文件范围和目标；移动会改变网盘里的位置，不把单纯搜索或查看扩展成整理任务。

单次调用的 FID 数量遵守 SDK/命令实际限制；大范围操作拆成小组，报告每组结果，不因一组失败就对整批盲目重试。

成功结果含 `fids`、`targetFid`，以及可选的 `move_path`。仅在最终成功后报告已移动。失败或超时后先核对现状，再决定是否重试；对整批搜索结果移动前，确认取回的数据确实覆盖用户选定范围。

## 技能层「删除」= 可逆隔离（非永久删除）

本 CLI **没有**永久删除/清空回收站/释放空间的底层 API。用户要求删除网盘文件时，技能层用现有 **创建目录 + 移动** 实现可逆隔离：

1. 说明语义：这是移入隔离区，**不是**永久抹除；通常**不回收**套餐空间；文件可从隔离目录移回。
2. 在根目录解析或创建 `待删除`：

```bash
./scripts/quark-drive.cjs create-folder --dir-path '待删除' --parent-fid '0'
```

3. 选定目标：可直接使用上一步返回的 `待删除` FID；需要按次隔离时，再在其下创建任务子目录，并用该子目录 FID 作为移动目标：

```bash
./scripts/quark-drive.cjs create-folder --dir-path '<任务子目录名>' --parent-fid '<待删除目录FID>'
```

4. 将**已选定**的云端 FID 分批移动到目标：

```bash
./scripts/quark-drive.cjs move '<FID1>' '<FID2>' --target-fid '<待删除或任务子目录FID>'
```

执行前基于完整的范围内源列表与明确选中的 FID；不要仅凭文件名模式或全局搜索命中数推断应删集合。内容、父目录或范围不确定时先问清。

### 隔离删除边界

- 用户明确要求删除/清掉某批网盘文件时，可按上述隔离流程执行，但必须先说明可逆隔离语义。
- 选中范围或分类有歧义时先澄清，不猜测。
- `待删除` 只挂在根 `0` 下；可选任务子目录挂在 `待删除` 的返回 FID 下。不要把用户源目录当成根。
- 保留未选中的文件；记录源父目录 FID/路径、选中 FID 列表、实际目标 FID/路径，便于恢复。
- 不附带分享、下载或其他无关写操作。
- 报告实际成功移动数量与部分失败；不对失败项做大范围盲目重试。
- `upload delete` / `download delete` 只管理本地传输任务记录，**不是**网盘文件删除。

## 结果与边界

这些命令用 `type: "result"` 返回最终结果，非零 `code` 结合 `msg` 判断原因。目录不存在、权限不足与认证过期分别处理，不一律通过登录重试。路径信息缺失不影响已成功操作，但不能补造保存位置。

本 CLI 没有复制、重命名或永久删除命令；技能层「删除」仅指本节的隔离移动。
